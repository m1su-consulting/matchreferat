## Version 1.0 – svenska

**Reklamtext (170)**
```
Referera barnens matcher i fotboll och innebandy live – mål, skott, straffar och byten med ett tryck. Dela en länk så kan mor- och farföräldrar följa matchen i realtid.
```

**Beskrivning**
```
Matchreferat är gjord för föräldrar och ledare som vill berätta hur det går när matchen inte sänds. I stället för att skriva i en chatt loggar du händelserna med stora knappar, och alla som har länken ser resultatet och tidslinjen i realtid.

FOTBOLL OCH INNEBANDY
• Välj sport på första sidan – appen kommer ihåg valet och du byter med ett tryck
• Fotboll: 5, 7, 9 eller 11 mot, halvlekar och minuter
• Innebandy: 3, 4 eller 5 mot 5, 2 eller 3 perioder och minuter

LAG OCH TRUPP
• Lägg in ett eller flera lag per sport
• Trupp med förnamn och tröjnummer – senaste uppställningen kommer ihåg
• Ändra dagens trupp och matchinställningar när som helst under matchen

UNDER MATCHEN
• Klocka med halvlekar eller perioder, pauser och tilläggstid (t.ex. 25+2')
• Logga mål med målskytt och assist, skott på mål och utanför, straffar och byten
• Fotboll: hörnor, frisparkar, gula och röda kort
• Innebandy: frislag och utvisningar (2, 5, 10 min eller matchstraff) med antal och minuter
• Ångra direkt om du tryckte fel
• Avsluta eller ta bort en match när du vill
• Allt får plats på en skärm – byggt för att användas med en hand vid sidlinjen

DELA
• Livelänk och QR-kod – de som följer behöver ingen app, länken öppnas i webbläsaren
• "Pågår nu" visar matcher som andra föräldrar delar via samma live-server
• Färdigt referat att kopiera eller dela i Messenger, SMS eller WhatsApp

INTEGRITET
• Inget konto och ingen reklam
• Bara förnamn och tröjnummer delas – efternamn lämnar aldrig telefonen
• Motståndarlaget anges bara med namn
• Delade matcher raderas när du stänger av delningen och slutar visas efter 7 dagar
```

## Information till granskaren (App Review)

Inloggning krävs: **Nej**

Från version 1.0.1 har appen ingen inbyggd server. Granskaren behöver en kopplingslänk för att testa Dela live. **Klistra in Mikaels kopplingslänk i App Store Connect, inte här** – repot är publikt och länken ger tillgång till hans Firebase-projekt.

```
Matchreferat lets a parent log events of a youth football match and optionally share a live link.

How to test (no login needed):
1. On the start page, tap "Prova med ett exempellag" (adds a team with fictional players), or "Lägg till lag" to create your own.
2. Tap "Ny match", choose the team, type any opponent name and tap "Starta".
3. Tap "Avspark" to start the clock, then use the buttons (Mål, Skott på mål, Hörna, Gult kort, Byte …). Each event can be undone from the toast at the bottom.
4. Live sharing needs a live server (a Firebase project the user owns or is given access to). To connect our test server, open this link on the device:
   <KOPPLINGSLÄNK>
   (or paste it under Inställningar → Live-server). The app tests the connection and confirms.
5. Go back to the match, tap "Dela live" at the top right and switch it on to get a link and QR code. Open the link in Safari to see the live page update as you log events. Switching it off deletes the shared match from the server.
6. "⋯" opens the timeline and a text report (Kopiera/Dela), today's squad and match settings. It also has "Avsluta match" (ends the match at the current score) and "Ta bort match" (asks first, then deletes the match and stops live sharing). The same two actions appear when you swipe left on the "Pågående match" card on the start page. Licenses are under Inställningar → Licenser.
7. When logging a shot ("Skott på mål"/"Skott utanför") you can pick the shooter or tap "Hoppa över"; a player is never required.
8. New in 1.0.2: when a live server is connected, the start page shows "Pågår nu", a list of matches that other people are sharing live on the same server (team names, score and minute only). To test it, share a match from one device and look at the start page on another device connected with the same link; tapping a match opens its live page. With nothing shared it shows "Inga matcher pågår just nu". Your own match is not listed there, it appears under "Pågående match".

Privacy: no account. Only team names, events and players as first name + shirt number are uploaded, and only to the live server the user has connected, and only when live sharing is on. Users connected to the same server see team names, score and minute of ongoing shared matches in "Pågår nu"; players and events are only on the live page. Shared matches are deleted when sharing stops. After 7 days without an update the Firestore rules refuse to read them, and the app deletes them from the server the next time it opens (Firestore TTL needs a paid plan, so the rules and the app enforce expiry instead). Privacy policy: https://matchreferat.web.app/integritet
```
